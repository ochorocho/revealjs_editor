The mermaid diagram slide template. Title (header) and optional prose (bodytext) use the editable `{record -> f:render.text(field: '...')}` pattern (visual_editor inline editing + TCA-type-aware escaping), exactly like Cover.html. The diagram source is emitted RAW-but-escaped via `{data.tx_revealjseditor_mermaid}` (the legacy row array, default Fluid htmlspecialchars) — NOT f:render.text: for a plain `text` field f:render.text applies nl2br, which would inject
tags and lose the real newlines that RevealMermaidMount.js needs when it reads `pre.textContent`. Default escaping keeps < > & as entities (so textContent round-trips) while preserving newlines. There is no inline editing of the source on the slide — it renders to an SVG; editors author it in the BE mermaid editor (renderType=mermaidEditor). RevealMermaidMount.js walks `.reveal [data-mermaid]` and replaces each block's content with the rendered (securityLevel:strict) SVG on the reveal `ready` / `slidechanged` events.
